# BNPL Credit Risk & Default Analysis

## Overview
Analysis of default risk patterns across 
10,345 BNPL transactions to identify 
vulnerable customer segments.

## Research Question
Does BNPL fulfil its promise of financial 
empowerment or disproportionately burden 
vulnerable users?

## Key Findings
- Overall default rate: 39.05%
- Missed payments strongest predictor 
  of default — 3+ missed payments 
  correlated with 80%+ default rate
- Students and unemployed users default 
  at nearly 49%
- Users aged 18-24 carry highest 
  default risk at 46.62%

## Tools
Python, SQL, SQLite, Power BI

## Data Source
Synthetic BNPL dataset via Kaggle
